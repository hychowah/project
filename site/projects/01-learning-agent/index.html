    INO — Personal AI Tutor

    Personal AI tutor with adaptive reviews, typed tool calls, multilingual concept search, and shared web and Discord interfaces.

    Overview

    Personal project, Mar 2026 – Present

    Work in progress.

    INO is a personal AI tutor that keeps track of concepts I am studying, generates review questions and records what I understand or confuse. I built a browser interface and an optional Discord bot around the same learning workflow, so conversations, questions and review history stay connected across both interfaces.

    A score-based schedule determines when to revisit each concept. The language model writes questions and grades answers using the concept’s history, learner notes and related ideas. The browser app also provides a knowledge explorer, a concept graph, review history and a forecast of upcoming reviews.

    View INO on GitHub →

    What I Built

    • A tutor that uses tools: the model searches concepts, retrieves notes, proposes new topics and runs reviews through typed tool calls. Python handlers validate arguments and return errors to the model when a request cannot be carried out.
    • Reviews with context: a shared question generator draws on previous answers and related concepts. Each quiz has an explicit record, so grading can only update concepts included in that quiz.
    • Knowledge organised with learner approval: new tracked concepts require confirmation. A weekly job proposes changes to the topic hierarchy, with renames, unlinking and deletions reviewed before they are applied.
    • Search across languages: a local multilingual embedding model finds related concepts alongside text search, including when the query and saved concept use different languages.

    Engineering Decisions

    The November 2026 rework focused on making the application easier to run and reason about. I replaced a custom text-parsing protocol with native LLM tool calls, keeping the model’s decisions separate from the code that executes them. Teaching prompts remain editable without changing the application logic.

    I also brought the API, optional Discord bot and scheduled jobs into one Python process. Concepts, conversations, review history and embedding vectors now live in one SQLite file. For this personal knowledge base, local embedding search with NumPy removes the need to operate a separate vector database.

    Daily backups, action logs and validation support recovery and troubleshooting. Backend tests cover tool behaviour, quiz state and review flows; frontend tests cover the main browser interfaces. This is a personal application built with pretrained models and external LLM APIs.

    Technologies

    Python · FastAPI · Pydantic · React · TypeScript · SQLite · discord.py · LLM tool calling · fastembed / ONNX · NumPy
