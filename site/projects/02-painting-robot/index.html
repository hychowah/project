    Suspended Painting Robot

    Mechanical design, robot software and operator tools for an industrial painting robot, from prototypes to field deployment.

    Overview

    C3 Construction Robotics, Mar 2024 – Aug 2026

    I was the lead engineer on a suspended painting robot for industrial tanks, taking the system from proof of concept through field deployment and a later roller-end-effector redesign. The project aimed to apply coating to a target thickness while working on a large outdoor surface.

    My responsibilities connected mechanical design, custom electronics, embedded interfaces, robot control software and operator tools. I followed the work through design, prototype integration, site testing and subsequent changes to the machine.

    In the News

    HK01 · 18 August 2026 · Chinese

    Roller-coating robotics for industrial tank maintenance ↗

    HK01 reports on the collaboration between C3 Construction Robotics, Towngas and Hong Kong Science and Technology Parks Corporation, including site trials and the transition from spray to roller coating.

    Mechanical Development

    I designed the robot structure, end effectors and electronics enclosures, using CAD, structural analysis and physical prototypes to develop the hardware. The work involved considering how individual parts would be manufactured, assembled, maintained and integrated into the robot.

    I also developed custom electronics and worked across the interfaces between the mechanism, actuators, sensors and embedded controllers. Building and testing the assembled system helped connect mechanical decisions with the behaviour seen during operation.

    Robot Software And System Integration

    I developed Python and C++ software around ROS2 to coordinate the robot hardware, sensor feedback and operator commands. My work included device interfaces, status monitoring and the integration needed for manual control and automated operation to use the same underlying system.

    The control work included prototype stabilisation and end-effector alignment, supported by sensor integration. Troubleshooting crossed mechanical, electrical and software boundaries: checking device behaviour, tracing command and feedback paths, and testing changes on the physical robot.

    Operator Interface And Automated Workflows

    I built a handheld Linux interface in Python and Qt/QML, bringing robot controls, live status and camera views into one place. Operators could monitor the system and move between manual commands and automated workflows during testing and operation.

    I also developed an editable workflow system for coordinating robot actions. Operators could build and save sequences, follow execution progress, and pause or stop a run. This supported changes to operating sequences as the hardware and coating process evolved.

    Software Testing And Diagnostics

    I added software tests around workflow behaviour, device interfaces and application startup, alongside diagnostic tools for development and troubleshooting. These provided ways to check changes before returning to physical testing.

    Connection monitoring, live video and recording helped make system behaviour visible during tests and field operation. This work supported the practical task of identifying what needed attention and tracing issues across the robot’s subsystems.

    Field Testing And Design Iteration

    I supported proof-of-concept trials and live site deployment, investigating hardware and software issues under outdoor operating conditions. I later led the roller-end-effector redesign and subsequent site testing as the project moved from spray to roller coating.

    Field observations fed back into mechanical changes, control adjustments and operator-workflow refinements. My role carried those changes across the hardware and software so they could be tested together as a working robot.

    Tools: ROS2 · Python · C++ · Qt/QML · SolidWorks
