    Suspended Painting Robot

    Mechanical design, robot software and operator tools for an industrial painting robot, from prototypes to field deployment.

    Project focus

    Overview

    C3 Construction Robotics, Mar 2024 – Aug 2026

    I was the lead engineer on a suspended painting robot for industrial tanks. My work covered mechanical design, custom electronics, embedded control and the operator application, taking the system from proof of concept through live spray-painting deployment and a later roller-end-effector redesign.

    The engineering challenge was to bring the coating tool, suspended platform and control system together around a target coating thickness. Development involved building the hardware, making its behaviour visible to the operator, and carrying observations from physical tests back into the design.

    Mechanical Development

    I designed the robot structure, end effectors and electronics enclosures in SolidWorks, using structural analysis and physical prototypes to develop the assemblies. The work connected the load-carrying structure with the moving hardware, tool attachments and equipment that had to be carried on the suspended machine.

    Manufacturing, assembly and access for wiring and maintenance were part of the design work. I followed parts through prototype assembly and integration, checking how the mechanical arrangement accommodated actuators, sensors and the rest of the robot.

    From Spray To Roller Coating

    After the initial spray-painting deployment, I led the mechanical development of a roller-based end effector. Changing the coating method affected how the tool met the surface, how it was positioned and oriented, and how its movement related to the travel of the suspended platform.

    I developed the revised end-effector hardware and supported assembly and site testing. This required mechanical changes and control adjustments to be considered together: the tool geometry, its motion and the way the operator commanded it all contributed to the coating process.

    Mechanical Prototyping And Field Iteration

    Prototype assemblies brought the structure, actuation and sensors together so fit and movement could be checked on the physical machine. I used observations from bench and outdoor testing to investigate mechanical behaviour and refine the hardware.

    My role continued through assembly, troubleshooting and subsequent design changes. This gave me responsibility for how the CAD design behaved once connected to the electronics and control software, and for carrying those findings into the next prototype.

    Robot Software And System Integration

    I developed a Python operator application with PySide6/QML and ROS2, alongside C++ end-effector control nodes. Together, these connected the operator’s commands to robot hardware and returned device state, sensor feedback and execution progress to the interface.

    The software supported both manual operation and saved operating sequences through shared device interfaces. I also worked on separating communication and background processing from the interface, so incoming telemetry, video and device activity could be handled while the operator continued using the controls.

    Operator Interface And Automated Workflows

    The handheld Linux interface brought manual controls, live camera views, device status and workflow progress into one place. I developed the operator-facing controls and the integration behind them, including transitions between direct commands and automated execution.

    I also built an editable workflow system. Operators could create, save and validate sequences, coordinate sequential or parallel actions, and use timing or position feedback to determine when actions progressed. Pause, resume, stop and repeated runs supported testing and changes to operating sequences as the hardware and coating process developed.

    Geometry And Prototype Control

    I developed software to estimate wall distance and orientation from LiDAR geometry and combine wall-angle observations with IMU rotation feedback. This supplied information for investigating the end effector’s alignment relative to the working surface.

    The C++ control work included prototype stabilisation and roller steering, connecting sensor feedback, target commands and actuator behaviour. These controls were developed and refined through testing on the physical machine alongside changes to the hardware.

    Software Testing And Diagnostics

    I added tests around workflow behaviour, device commands, communication-loss handling and application startup. Development tools also included simulated modes and a node-level smoke-test harness for checking parts of the system without the complete robot setup.

    Live telemetry, camera streaming, recordings and diagnostic logs helped make system behaviour visible during testing. I developed connection monitoring, application-level stop handling and recovery paths for device and video connections, supporting troubleshooting across the operator application and the robot.

    Electronics And Embedded Integration

    I developed custom electronics and integrated the electrical interfaces between sensors, actuators and embedded controllers. The work connected power distribution, motor control and sensor feedback with the mechanisms and the higher-level robot software.

    I followed this through wiring, prototype assembly and bench integration. Bringing the electronics into the assembled machine meant checking the complete command-and-feedback path: an operator action had to reach the intended device, and its state had to return to the host application.

    Embedded Firmware And Device Feedback

    I developed microcontroller firmware for motor-driven mechanisms and end-effector devices, including motion commands, homing and position feedback. Sensor interfaces supplied information about the mechanism and its orientation to the host control system.

    Board monitoring also exposed electrical and operating state, including voltage, current and temperature. These readouts brought device-level information into the operator and diagnostic tools, helping with setup and investigation of hardware behaviour during integration.

    Communication And Hardware Diagnostics

    I implemented the serial connection between the host control software and the embedded controller, using shared message definitions and integrity checks for commands and feedback. The host interface decoded device state and included reconnection handling.

    This interface work linked firmware development with practical testing of the assembled robot. I traced issues across commands, electrical connections, device feedback and mechanism movement, using the combined observations to guide hardware and software changes.

    Field Deployment And Iteration

    I supported proof-of-concept trials, live spray-painting deployment and later roller-system site testing. The project brought mechanical, electronics and software work into the same development cycle: field observations informed hardware changes, control adjustments and operator-workflow refinements.
